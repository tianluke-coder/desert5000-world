# 殷玉珍案例｜不是“5000美元自动变成5万棵树”

## 关键时间线

### 1985
殷玉珍来到毛乌素沙地腹地生活。

### 1986
她卖掉一只羊，买回600棵树苗。
一场大风以后，存活不到10棵。

这说明一个重要事实：

> “把树种下去”本身并不等于治沙成功。

### 后来的方法变化
国家林草局资料记载，她不断试错，逐渐形成了更复杂的方法：

1. 先让流沙相对稳定；
2. 使用沙柳、柠条、紫穗槐等灌木；
3. 条件改善后，再配置杨树、榆树等乔木。

这不是一条固定公式，而是多年实践形成的经验。

### 1999
美国教师罗纳德·萨科尔斯基（“赛考斯”）筹集5000美元，
帮助殷玉珍夫妇治沙造林。

新华社2026年报道：
当年这笔善款购买栽种的树苗，如今已经长成5万多棵大树。

### 2007以后
真实变化不仅来自个人劳动。

当地政府修建了通往殷玉珍家的8公里柏油路；
“三北”工程及地方专项资金提供了部分苗木、项目和设备支持。

### 更大的尺度
国家林草局2026年资料显示：

- 40余年来，殷玉珍家周边7万余亩沙地得到治理；
- 累计栽种树木超过800万棵；
- 乌审旗境内毛乌素沙地治理率达到85%。

## 建模提醒

不要把这个案例建模成：

`5000美元 → 5万棵树`

更值得研究的是：

`资金 + 劳动 + 方法 + 水 + 风 + 植物 + 基础设施 + 政府工程 + 社会参与 + 时间 + 不确定性`

怎样共同改变一个地方。
